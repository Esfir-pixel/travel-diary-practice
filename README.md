# Дневник путешествий

Веб-приложение для записи и просмотра путешествий. Часть мульти-приложения на общей БД Supabase (вместе с «Книжным магазином»).

## Стек

- Next.js 16 (App Router, Server Actions, Server Components)
- TypeScript
- Supabase (PostgreSQL, Auth, Storage, RLS)
- UI-библиотека  React 19
- shadcn/ui (Base UI) + Tailwind CSS 4
- Leaflet + OpenStreetMap (интерактивная карта)
- lucide-react (иконки)

## Возможности

-  Регистрация и вход (Supabase Auth)
-  Создание путешествия с обложкой, локацией, стоимостью
-  Привязка к геопозиции (интерактивная карта, клик = координаты)
-  Оценка безопасности (1–5)
-  Публичная лента путешествий всех пользователей
-  Личный кабинет «Мои путешествия»
-  Редактирование и удаление своих записей
-  RLS-политики: чужие записи только читать, свои — редактировать
-  Приватные путешествия (не видны в общей ленте)
